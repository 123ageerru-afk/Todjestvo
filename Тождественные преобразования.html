Сложение и вычитание алгебраических дробей

От простого к сложному: разбираем правила, алгоритмы и тренируемся на задачах трёх уровней.

8 класс теория + практика с ответами
2 ПОВТОРЕНИЕ

📘 Что такое алгебраическая дробь

Это выражение вида AB, где A и B — многочлены, причём B ≠ 0.

x + 3x − 5    a² − 4a + 2    2mm² + 1

💡 Правила сложения и вычитания дробей — те же, что и для обыкновенных дробей. Только с буквами.
3 ВСПОМИНАЕМ

🔢 Как было с числами

Одинаковый знаменатель

27 + 37 = 57

Разные знаменатели

12 + 13 = 36 + 26 = 56

📌 С алгебраическими дробями мы будем делать то же самое — приводить к общему знаменателю и складывать числители.
4 ПРАВИЛО · ОДИНАКОВЫЙ ЗНАМЕНАТЕЛЬ

➕ Сложение с одинаковым знаменателем

Если знаменатели одинаковые, складываем (или вычитаем) только числители, а знаменатель оставляем без изменений:

AC + BC = A + BC

AC − BC = A − BC

⚠️ Знаменатель НЕ складываем! Он остаётся прежним.
5 ЛЁГКИЙ УРОВЕНЬ

🌸 Пример 1: плюс с одинаковым знаменателем

Вычислить:  3xx + 2 + 2xx + 2

Знаменатели одинаковые — (x + 2). Значит, работаем с числителями.
Складываем числители: 3x + 2x = 5x.
Знаменатель сохраняем: (x + 2).
Ответ: 5xx + 2
💡 ОДЗ: x ≠ −2 (знаменатель не должен быть нулём).
6 ЛЁГКИЙ УРОВЕНЬ

🌸 Пример 2: минус с одинаковым знаменателем

Вычислить:  5aa − 3 − 2aa − 3

Знаменатели одинаковые.
Вычитаем числители: 5a − 2a = 3a.
Ответ: 3aa − 3
⚠️ Если в числителе после вычитания получается многочлен из нескольких членов — обязательно бери его в скобки!
7 ВАЖНО

⚠️ Зачем нужны скобки при вычитании

❌ Ошибка

Пишут: x + 3x − 1 − x − 2x − 1 = x + 3 − x − 2x − 1

Минус перед дробью относится ко ВСЕМУ числителю, а не только к первому слагаемому.

✅ Правильно

Берём в скобки: x + 3 − (x − 2)x − 1

= x + 3 − x + 2x − 1 = 5x − 1

⚠️ Правило: если после дроби стоит минус, а в числителе два и более слагаемых — ВСЕГДА ставь скобки и раскрывай их с изменением знаков.
8 СРЕДНИЙ УРОВЕНЬ

🌺 Пример 3: вычитание со скобками

Вычислить:  x + 5x − 2 − x + 1x − 2

Знаменатели одинаковые — оставляем.
Числитель берём в скобки: (x + 5) − (x + 1)x − 2
Раскрываем: x + 5 − x − 1 = 4.
Ответ: 4x − 2
9 ПРАВИЛО 2

🎯 Если знаменатели разные

Порядок действий:

Разложи каждый знаменатель на множители.
Найди общий знаменатель — наименьший общий (НОК).
Найди дополнительный множитель для каждой дроби.
Умножь числитель и знаменатель каждой дроби на её дополнительный множитель.
Сложи или вычти числители, знаменатель оставь общим.
📌 Наименьший общий знаменатель (НОЗ) — это произведение всех различных множителей в наибольшей степени.
10 АЛГОРИТМ НОЗ

🔧 Как найти общий знаменатель

Пример

Знаменатели: (x − 2) и (x + 3)

Разных множителей нет — общий знаменатель = (x − 2)(x + 3).

Второй пример

Знаменатели: x и x²

Общий знаменатель = x² (множитель x берём в наибольшей степени).

Третий пример

Знаменатели: (x − 1)(x + 1) и (x + 1)

Общий = (x − 1)(x + 1). Он уже включает второй знаменатель.

💡 Не всегда нужно перемножать знаменатели целиком — иногда один уже содержится в другом.
11 ЛЁГКИЙ УРОВЕНЬ

🌸 Пример 4: буквы в знаменателях

Вычислить:  1x + 1y

Общий знаменатель: xy.
Доп. множитель для первой дроби: y. Получаем yxy.
Доп. множитель для второй: x. Получаем xxy.
Складываем: y + xxy
💡 ОДЗ: x ≠ 0, y ≠ 0.
12 ЛЁГКИЙ УРОВЕНЬ

🌸 Пример 5: число + дробь

Вычислить:  1 + 1x

Представим единицу как дробь: xx
Общий знаменатель: x.
Складываем: x + 1x
⚠️ Любое число можно записать дробью: 1 = xx, 5 = 5xx и так далее. Но не забудь: x ≠ 0.
13 СРЕДНИЙ УРОВЕНЬ

🌺 Пример 6: два разных знаменателя

Вычислить:  1x − 1 + 1x + 1

Общий знаменатель: (x − 1)(x + 1).
Первая дробь: домножаем на (x + 1): x + 1(x − 1)(x + 1)
Вторая дробь: домножаем на (x − 1): x − 1(x − 1)(x + 1)
Складываем числители: (x + 1) + (x − 1) = 2x.
Ответ: 2x(x − 1)(x + 1)
14 СРЕДНИЙ УРОВЕНЬ

🌺 Пример 7: разложить знаменатель

Вычислить:  1x² − 4 + 1x + 2

Разложим первый знаменатель: x² − 4 = (x − 2)(x + 2).
Второй знаменатель: x + 2 уже содержится в первом!
Общий знаменатель: (x − 2)(x + 2).
Доп. множитель для второй дроби: (x − 2).
Числитель: 1 + (x − 2) = x − 1.
Ответ: x − 1(x − 2)(x + 2)
💡 Всегда сначала раскладывай знаменатели на множители — тогда видно, что уже совпадает.
15 СЛОЖНЫЙ УРОВЕНЬ

🌷 Пример 8: вычитание с разложением

Вычислить:  3x² − 9 − 1x − 3

Разложим первый знаменатель: x² − 9 = (x − 3)(x + 3).
Второй знаменатель (x − 3) уже содержится в первом.
Общий знаменатель: (x − 3)(x + 3).
Доп. множитель для второй дроби: (x + 3).
Числитель: 3 − (x + 3) = 3 − x − 3 = −x.
Ответ: −x(x − 3)(x + 3)
⚠️ Не забудь про скобки: −(x + 3), а не −x + 3.
16 СЛОЖНЫЙ УРОВЕНЬ

🌷 Пример 9: два разных разложения

Вычислить:  xx² − 4 − 1x² + 4x + 4

Первый знаменатель: x² − 4 = (x − 2)(x + 2).
Второй знаменатель: x² + 4x + 4 = (x + 2)².
Общий знаменатель: (x − 2)(x + 2)². Берём (x + 2) в наибольшей степени.
Доп. множитель первой дроби: (x + 2). Числитель: x(x + 2).
Доп. множитель второй дроби: (x − 2). Числитель: 1·(x − 2).
Разность числителей: x(x + 2) − (x − 2) = x² + 2x − x + 2 = x² + x + 2.
Ответ: x² + x + 2(x − 2)(x + 2)²
17 ОСОБЫЙ СЛУЧАЙ

🌷 Пример 10: противоположные знаменатели

Вычислить:  5a − b + 3b − a

📌 Заметь: (b − a) = −(a − b).
Перепишем вторую дробь: 3b − a = −3a − b
Теперь знаменатели одинаковые.
Складываем числители: 5 + (−3) = 2.
Ответ: 2a − b
💡 Если знаменатели отличаются только знаком, вынеси минус за дробь — знаменатели станут одинаковыми.

20 ПРАКТИКА · СЛОЖНАЯ

🔥 Реши сам — уровень 3

1) xx² − 4 − 1x² + 4x + 4
2) 3x² − 9 − 1x − 3
3) a + 2a² + 2a − 1a
1. x² − 4 = (x − 2)(x + 2); x² + 4x + 4 = (x + 2)².
Общий знаменатель: (x − 2)(x + 2)².
Числитель: x(x + 2) − (x − 2) = x² + 2x − x + 2 = x² + x + 2.
Ответ: x² + x + 2(x − 2)(x + 2)²

2. x² − 9 = (x − 3)(x + 3).
Числитель: 3 − (x + 3) = −x.
Ответ: −x(x − 3)(x + 3)

3. a² + 2a = a(a + 2).
Числитель: (a + 2) − (a + 2) = 0.
Ответ: 0 — при условии a ≠ 0, a ≠ −2.
21 ОШИБКИ

💡 Четыре ошибки, которых нужно избегать

Ошибка 1. Складывать знаменатели.

❌ ab + cd ≠ a + cb + d

Ошибка 2. Не ставить скобки при вычитании.

❌ x − (a − b) → x − a − b · ✅ x − a + b

Ошибка 3. Сократить слагаемые вместо множителей.

❌ x + 33 ≠ x

Ошибка 4. Забыть про ОДЗ. Пиши «x ≠ …» сразу.
